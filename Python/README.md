# Python

Prerequisite for the current examples: Python 3.9 or newer.

Create one folder per topic, such as `Python/two-sum/`. Use names such as `solution.py`, `brute_force.py`, or `hash_map.py` for source files.

Run the current local practice file from the repository root:

```sh
python3 Python/two-sum/practice.py
```

For exercises that need packages, keep their dependency files inside the topic folder and use a local `.venv` environment.

Practice files contain a TODO for your implementation and a runner for example checks. Reference files contain completed solutions.
