# Python

Prerequisite: Python 3.

Create one folder per topic, such as `Python/two-sum/`. Use names such as `solution.py`, `brute_force.py`, or `hash_map.py` for source files.

Run the current example from the repository root:

```sh
python3 Python/two-sum/solution.py
```

For exercises that need packages, keep their dependency files inside the topic folder and use a local `.venv` environment.
