# React

Prerequisites for runnable applications: Node.js and the package manager specified by the exercise.

Create one folder per topic, such as `React/todo-app/`. Use descriptive component names such as `TodoApp.jsx` or `TodoApp.tsx`.

Keep each runnable application's `package.json`, dependency lockfile, `src` folder, and setup instructions together. Document the actual scripts for starting, building, and testing that application in its README. The shared repository root is the practice index.
