# Go

Prerequisite: Go.

Create one folder per topic, such as `Go/two-sum/`. Put independently runnable reference and practice programs in separate folders when each defines `main` or other functions with the same name.

Keep an exercise's `go.mod` and `go.sum` with its source when it is a Go module. Document run and test commands in the topic README.
